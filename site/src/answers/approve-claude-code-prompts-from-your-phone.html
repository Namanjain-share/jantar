How do I approve a Claude Code permission prompt from my phone?

answered for v{{version}}{{release-on}}

Run Jantar on your Mac and pair your phone with it. When a Claude Code session in Terminal stops on a permission prompt, a plan or a question, the phone shows it in Claude's own words, with Claude's own options as buttons. With Jantar's hooks installed, your tap goes back through Claude Code itself. Without them, Jantar types your choice into Terminal, and only while the Mac still shows exactly the dialog you tapped.

Steps

On the Mac, once Jantar is installed (one line, or by hand), give your phone a way in through Tailscale or a Cloudflare Tunnel, pair it, and install Claude Code's hooks:

jantar remote setup           # how the phone reaches this Mac
jantar pair                   # a QR code, good once, for 10 minutes
jantar hooks install          # a dry run: what it would change
jantar hooks install --apply  # asks, then keeps a backup

On the phone, open the paired link, choose Add to Home Screen and turn notifications on under Devices. On an iPhone, notifications need the Home Screen app, on iOS 16.4 or newer.

A session picks up the hooks when it next starts. One that was already running keeps going without cards, and the phone answers its dialogs through the screen instead.

What it does not do

  • Answer for you. Every answer is a tap. Rows that save a rule or switch Claude to a mode that doesn't ask take a 2-second hold.
  • Answer every screen. Forms and lists it can't turn into buttons get a keypad, and a dialog taller than the Terminal window gets no buttons at all. Each case that stays at the Mac says why.
  • Change Claude when it is stopped. The hooks fail open: with Jantar not running, Claude behaves as usual.
  • Run anywhere but a Mac with Terminal.app, today. Linux servers with tmux come in v0.6.

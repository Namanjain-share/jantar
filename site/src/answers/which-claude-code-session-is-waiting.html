How do I see which Claude Code session is waiting for me when I run many in Terminal?

answered for v{{version}}{{release-on}}

Jantar's board lists every Claude Code session in Terminal.app, the ones that need you first, and each row says what it waits on: the question, the plan or the command. The same board is on the Mac and on your phone, and the phone can get a push when a session needs you.

Steps

On the Mac, once Jantar is installed (one line, or by hand):

jantar status    # the board in this Terminal: your turn first
jantar open      # the board in this Mac's browser
jantar pair      # the same board on your phone

The board has four rails: needs you (the oldest wait first), your turn, working and ended. Each row shows what the session waits on, the tool it is running or its last reply. On a Mac, the Desk beside the board holds up to three cards to answer, and the keys 1 to 9 open the nth session that needs you.

What it does not do

  • Read other terminals. Terminal.app only today; Linux servers with tmux come in v0.6, iTerm2 and Ghostty after.
  • Type on its own. It reads Claude Code's session files and Terminal's text, and types only what you send or answer.
  • Push to a phone that has not turned notifications on under Devices. On an iPhone they need the Home Screen app.
